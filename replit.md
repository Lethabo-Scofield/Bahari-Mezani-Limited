# Bahari Mezani Limited

## Run locally

This is a Vite + React marketing website. The development server runs on port 5000:

```bash
npm run dev
```

The site includes responsive routes for `/`, `/about`, `/cold-storage`, `/products`, `/impact`, and `/contact`.

## Content notes

WhatsApp calls-to-action use `+254 768 066 569`. Contact form submissions are currently presented as a confirmation state in the frontend; connect the form to the preferred email service before launch.
